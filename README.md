# PetroLoop — Petrochemical Data Storytelling Dashboard

## ขอบเขตอุตสาหกรรม
เน้นส่วนโพลิเมอร์ พลาสติก และวัตถุดิบหมุนเวียนที่เกี่ยวข้องกับอุตสาหกรรมปิโตรเคมี ไม่ได้อ้างว่าครอบคลุมปิโตรเคมีทั้งหมด เช่น สารอะโรเมติกส์ ตัวทำละลาย และปุ๋ย ข้อมูลเป็นระดับโลก ไม่ใช่ข้อมูลประเทศไทย โรงงานใดโรงงานหนึ่ง หรือผลของแบรนด์ PetroLoop

PetroLoop เป็นชื่อแนวคิดที่ออกแบบเพื่อการศึกษา ไม่ใช่บริษัทที่มีผลประกอบการจริง

## เรื่องที่เล่า
1. **ACT 1: Growth & pressure** — เปรียบเทียบการผลิตและขยะระหว่างปี 2000 กับ 2019 และสัดส่วนพลาสติกทุติยภูมิ ถามว่าภาระปลายทางโตเร็วเพียงใด
2. **ACT 2: Recovery gap** — ดูปลายทางขยะและช่องว่างระหว่างรวบรวมกับรีไซเคิลสำเร็จ เพื่อกำหนดโจทย์การคัดแยก คุณภาพ และการติดตามวัตถุดิบ
3. **ACT 3: Circular opportunity** — ใช้กลุ่มการใช้งานชี้จุดเริ่มศึกษา ทดลองเป้าหมายเชิงปริมาณ และเสนอช่องทางรายได้โดยไม่สร้างรายได้จริงขึ้นมา

## Dataset และแหล่งอ้างอิงจริง
**ชื่อฐานข้อมูล:** OECD Global Plastics Outlook Database

**รายงาน:** OECD (2022), *Global Plastics Outlook: Economic Drivers, Environmental Impacts and Policy Options*, OECD Publishing, Paris.
- รายงาน DOI: https://doi.org/10.1787/de747aef-en
- ฐานข้อมูล DOI: https://doi.org/10.1787/c0821f81-en
- หน้าที่ใช้ถอดตัวเลข: https://www.oecd.org/en/publications/global-plastics-outlook_de747aef-en/full-report/component-6.html
- §1.3.1 และ Figure 1.1: การผลิต ขยะ การจัดการขยะ และเส้นทางรีไซเคิล
- §1.4.1 และ Figure 1.3: การผลิตพลาสติกทุติยภูมิ
- แหล่งสำรวจต่อ: OECD Data Explorer — Plastics Use in 2019: https://data-explorer.oecd.org/vis?df%5Bag%5D=OECD.ENV.EEI&df%5Bds%5D=dsDisseminateFinalDMZ&df%5Bid%5D=DSD_PU_2019%40DF_PU_2019
- วันที่ตรวจแหล่งอ้างอิง: 5 ตุลาคม 2026

`PetroLoop_Source_Data.csv` เป็น **curated extract 16 แถวที่ถอดค่าจากรายงาน** ไม่ใช่ไฟล์ดิบที่ดาวน์โหลดจาก OECD ไม่ใช่การเชื่อม API และไม่มีการเพิ่มข้อมูลจำลองลงในข้อมูลต้นทาง ค่าจาก OECD เป็นค่าประมาณเชิงประวัติศาสตร์จากฐานข้อมูล/แบบจำลอง ไม่ใช่การวัดโรงงานแบบสด ชุดข้อมูลปี 2019 ถูกเลือกเพื่อรักษาขอบเขตและฐานการเปรียบเทียบให้ตรงกัน ไม่ได้อ้างว่าเป็นข้อมูลล่าสุด

### Data dictionary
| คอลัมน์ | ความหมาย |
|---|---|
| Year | ปีอ้างอิง ค.ศ. 2000 หรือ 2019 |
| Geography | World เท่านั้น |
| Metric | กลุ่มตัวชี้วัด เช่น plastic_waste, recycling_flow |
| Category | หมวดหมู่ภายในตัวชี้วัด |
| Value | ตัวเลขตามแหล่งอ้างอิง |
| Unit | Mt = ล้านตัน; percent = เปอร์เซ็นต์ 0–100 |
| Data_Status | OECD historical estimate |
| Note | การปัดเศษและข้อจำกัดของค่า |
| Source_URL | URL ต้นทางสำหรับตรวจสอบ |
| Source_Section | หัวข้อหรือรูปในรายงาน |
| Accessed | วันที่ตรวจแหล่งอ้างอิง |

ห้าม SUM ค่า Value ทั้งตาราง เพราะมีหลายหน่วยและข้อมูลซ้อนกัน เช่น Collected = Ultimately_recycled + Residues; ตัวกรองปีไม่ควรทำให้ตัวชี้วัดที่ไม่มีข้อมูลกลายเป็น 0

## สูตรที่ใช้
- การผลิตเพิ่ม: (460 / 234 − 1) × 100 = 96.6%
- ขยะเพิ่ม: (353 / 156 − 1) × 100 = 126.3%
- ส่วนทุติยภูมิ: 29.1 / 460 × 100 = 6.3%
- ส่วนที่เหลือของการผลิต: 460 − 29.1 = 430.9 Mt
- รวบรวมต่อขยะทั้งหมด: 55 / 353 × 100 = 15.6%
- รีไซเคิลสำเร็จต่อขยะทั้งหมด: 33 / 353 × 100 = 9.35% ก่อนปัดเศษ (Dashboard แสดง 9.3%); headline 9% ใช้ตามรายงาน
- เศษตกค้างต่อปริมาณรวบรวม: 22 / 55 × 100 = 40%
- กลุ่มการใช้งานอื่น: 100 − 40 − 12 − 11 = 37%
- What-if ปริมาณตามเป้าหมาย = 353 × เป้าหมาย / 100
- What-if ปริมาณเพิ่มจากฐาน = ปริมาณตามเป้าหมาย − 33
- ค่าเริ่มต้น 20%: เป้าหมาย 70.6 Mt; เพิ่ม 37.6 Mt
- สถานการณ์คงขยะโลกไว้ที่ 353 Mt ไม่มีปีเป้าหมาย ไม่ได้เป็นการพยากรณ์ของ OECD

## การออกแบบและแนวคิดธุรกิจ
**กลุ่มผู้ใช้ Dashboard:** ผู้วางแผนธุรกิจโพลิเมอร์ ผู้จัดหาวัตถุดิบรีไซเคิล ผู้จัดการความยั่งยืน และผู้เรียนที่นำเสนอ data storytelling

**Pain points ที่นำไปตรวจสอบต่อ:** ความไม่ต่อเนื่องของวัตถุดิบ สิ่งปนเปื้อน คุณสมบัติไม่ตรงเกรด และการตรวจสอบย้อนกลับ ตัวเลข OECD ใช้ตั้งโจทย์ระดับระบบ ไม่ได้พิสูจน์ความรุนแรงของทุกปัญหาในทุกโรงงาน

**Value proposition ของแนวคิด:** ช่วยเชื่อมข้อมูลแหล่งวัตถุดิบ การคัดแยก ผลการทดสอบคุณภาพ และผู้ซื้อเม็ดพลาสติก เพื่อทดลองเพิ่มปริมาณที่ผ่านข้อกำหนด

**ลูกค้า:** ผู้ผลิต/compounder เม็ดพลาสติก ผู้แปรรูปบรรจุภัณฑ์ ผู้รีไซเคิล และเจ้าของแบรนด์ที่ใช้วัสดุรีไซเคิล

**รายได้ที่เสนอ:** ขายวัสดุผ่านเกณฑ์; ค่าบริการคัดแยก/แปรรูป; ค่าบริการติดตามข้อมูล ไม่แสดงยอดขาย กำไร ROI หรือ recurring share เพราะไม่มีฐานข้อมูลธุรกรรมจริง

**Partners / Activities:** ผู้รวบรวม ผู้รีไซเคิล ห้องทดสอบ ผู้แปรรูป / ทดลองกระบวนการ ควบคุมคุณภาพ และเชื่อมข้อมูล

**Channels / Relationships:** B2B pilot กับผู้ซื้อวัตถุดิบ สัญญาระยะยาวหลังผ่านการทดสอบ และรายงานคุณภาพรายล็อต

**SWOT แบบแนวคิด:** จุดแข็งคือการเชื่อมข้อมูลตลอดกระบวนการ; จุดอ่อนคือยังไม่มีหลักฐานโรงงาน; โอกาสคือส่วนทุติยภูมิยังเล็ก; ความเสี่ยงคือราคาวัสดุ คุณภาพ และข้อกำหนดปลายทาง ต้องศึกษาเพิ่มก่อนใช้ตัดสินใจลงทุน

**Visual identity:** Navy #102D3A; Teal #087F79; Soft background #F3F6F5; Amber #D07838 สำหรับสมมติฐาน/การสูญเสีย; ฟอนต์ Sarabun; กราฟมีหน่วยและป้ายตรงจุด ไม่ใช้สีอย่างเดียวในการสื่อความหมาย

## ข้อจำกัดสำคัญ
- การผลิตในปีเดียวไม่จำเป็นต้องกลายเป็นขยะในปีเดียว จึงไม่นำ 460 − 353 ไปตีความเป็นประสิทธิภาพหรือสินค้าคงเหลือ
- 33 Mt ที่รีไซเคิลจากขยะ กับ 29.1 Mt การผลิตทุติยภูมิเป็นคนละตัวชี้วัด ห้ามสลับใช้
- สัดส่วนการจัดการขยะเป็นค่าปัดเศษ โดย landfill ≈50%; ไม่คูณส่วนเหล่านี้เพื่ออ้างปริมาณที่แม่นยำ
- 22% จัดการไม่เหมาะสม ไม่ได้หมายถึงรั่วลงทะเลทั้งหมด
- รายงานไม่ได้พิสูจน์ว่าเศษตกค้างทั้งหมดสามารถกู้กลับได้ หรือว่าวัสดุรีไซเคิลแทนวัตถุดิบใหม่ได้ทุกเกรด
- ไม่สร้างการแจกแจงชนิดโพลิเมอร์ ราคา คุณภาพ รายได้ หรือข้อมูลรายเดือนขึ้นเอง
- เป้าหมายรีไซเคิลไม่ได้เปลี่ยนข้อมูลย้อนหลังและไม่ได้ทำให้สัดส่วนใน Donut เปลี่ยนตาม
- Dashboard ฝัง snapshot ของ CSV ไว้เพื่อเปิด offline หากแก้ CSV ภายนอกต้องแก้ข้อมูลใน HTML และสร้าง PDF ใหม่ด้วย ไม่ใช่ live connection

## แนวทางนำไปทำ Power BI
นำ CSV เข้าเป็นตาราง long format กำหนด Value เป็น decimal, Year เป็น whole number; กรอง Metric/Unit/Year ให้ตรงก่อนทำ measure หลีกเลี่ยง SUM โดยไม่มีเงื่อนไข ทำ what-if parameter แยกจาก source table และไม่ join ตารางขยะกับการผลิตในระดับที่ทำให้ค่าซ้ำ กราฟกระบวนการต้องแสดงว่า 55 = 33 + 22 ไม่ใช่ 3 หมวดที่บวกกัน

## บทนำเสนอแบบย่อ
เริ่มจากการผลิตพลาสติกที่เกือบเพิ่มเป็นสองเท่าระหว่างปี 2000 และ 2019 แต่ขยะเพิ่มเร็วกว่า ต่อมามองการจัดการปลายทาง จะเห็นว่าจากขยะ 353 ล้านตัน มีเพียง 33 ล้านตันที่รีไซเคิลได้ในที่สุด ส่วนการรวบรวม 55 ล้านตันยังมีเศษตกค้าง 22 ล้านตัน จึงควรศึกษาทั้งการรวบรวมและคุณภาพกระบวนการ ปิดท้ายด้วยบรรจุภัณฑ์ซึ่งคิดเป็น 40% ของขยะโลก และทดลองเป้าหมาย 20% เพื่อเห็นขนาดปริมาณที่ต้องเพิ่ม โดยย้ำว่าตัวเลขสถานการณ์ไม่ใช่รายได้หรือผลการดำเนินงานจริง
